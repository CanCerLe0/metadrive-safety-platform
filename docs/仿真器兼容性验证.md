# MetaDrive 兼容性验证（Task 1）

验证日期：2026-11-26。目标环境：macOS arm64、Python 3.11.17、MetaDrive 官方 `MetaDrive-0.4.3` tag。该 tag 的发行包版本元数据是 `0.4.2.3`；源码固定为 commit `5bf8ea8909c4643a4099a250e6f5fb89c695d8b4`，`pyproject.toml` 和 `uv.lock` 均使用这一 SHA。系统 `python3` 是 3.9.6，探针只用项目 `.venv`。

## 原生导出、重载与出帧

最小复现：

```sh
export UV_CACHE_DIR="$PWD/.cache/uv"
export UV_PYTHON_INSTALL_DIR="$PWD/.cache/uv/python"
export MPLCONFIGDIR="$PWD/.cache/matplotlib"
uv python install 3.11
uv venv --python 3.11
uv sync --dev --locked
uv run --locked pytest tests/integration/test_native_probe.py -q
```

首次运行需要 MetaDrive 官方 release 的 `assets.zip`（约 134 MB）；本机第一次运行时从[官方 0.4.3 release](https://github.com/metadriverse/metadrive/releases/tag/MetaDrive-0.4.3)下载，放入虚拟环境中的 `metadrive/assets/`。若网络受限，`env.reset()` 会在 `BaseEngine.try_pull_asset()` 下载时失败。依赖与资源已在本机缓存后，可用 `uv sync --offline --locked` 和 `uv run --offline --locked` 复验。

`src/safety_platform/sim/probe.py` 用 MetaDrive `MetaDriveEnv.export_scenarios()` 录制双车道直路和自车轨迹，基于真实车道中心线加入一辆固定轨迹切入车，以 `ScenarioDescription.sanity_check()` 校验，再用 `save_dataset()` 写出场景 `.pkl`、`dataset_summary.pkl`、`dataset_mapping.pkl`。新建独立 `ScenarioEnv`，设 `reactive_traffic=False`，通过外部动作 `[0.0, 0.25]` 驾驶自车，读取重载后交通车的位置，并逐步调用 `env.render(mode="topdown", window=False, screen_size=(640, 360))`。两个环境均在 `finally` 中关闭。该原型只验证原生导出/加载/运行能力，不是 Task 2–3 的正式参数化生成器。

本机运行 `uv run --offline --no-sync pytest tests/integration/test_native_probe.py -q`：**1 passed**。另一次直接调用 `probe_native(Path("var/probe"))` 的实测结果：

| 项目 | 结果 |
| --- | --- |
| 场景 ID | `PGMap-0` |
| 数据集目录 | `var/probe/native_probe/`（不进入 Git） |
| 重载后步数 | 100 |
| 交通车跨越车道、自车移动 | 均为 true |
| 两个索引文件可读 | true |
| 真实俯视帧 | 连续 100 帧，640×360 RGB 非空，像素随运行变化 |
| 平均 `render` 调用耗时 | 1.01 ms/帧 |
| 进程峰值内存 | 306.3 MB |

第一次测试曾在 83 步结束：回放油门 `0.5` 比录制时 `0.25` 高，自车提前到达终点；将回放动作与录制动作一致后 100 步通过。这是调用配置差异。macOS 进程同时加载 pygame 与 cv2 的 SDL2 库时会打印 Objective-C 类重复警告；本次无界面俯视测试仍通过，但后续真实页面烟测需继续观察稳定性。

结论：锁定版在当前机器上通过原生 Scenario Description 数据集保存、索引读取、`ScenarioEnv` 重载、外部自车动作控制和连续真实俯视出帧门槛。Task 3 仍须单独证明三个正式模板的参数改动会改变重载轨迹。当前性能值是单次短场景测量，不能当作网页 5–10 FPS 或大批量运行的吞吐保证。
